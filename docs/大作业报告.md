## 摘要

医学影像诊断是典型的人类视觉认知任务。本项目以脑肿瘤 MRI 四分类（胶质瘤 / 脑膜瘤 / 垂体瘤 / 无肿瘤）为切入点，构建了一个从数据处理、模型训练、多维评估到 Web 交互演示的完整辅助诊断系统，并围绕"机器认知与人类认知的异同"开展系列对照实验。技术上，采用"先训练分类头、再微调深层"的两阶段迁移学习策略，在无 GPU 的普通笔记本上达到内部测试集 **93.0%** 的准确率；进一步将判别式分类头替换为**现代 Hopfield 联想记忆网络**，并追问"提升从何而来"——通过参数量对齐的 MLP 对照、5 种子重复实验与 McNemar 配对检验，发现记忆头 94.0% 对线性头 92.6% 的领先优势在 4/5 种子上统计显著（p<0.01），但与参数对齐 MLP 打平，说明收益主要来自更大的参数化头而非联想检索机制本身；记忆容量消融则表明每类 ≥8 条记忆后性能饱和且稳定。认知维度上：跨来源外部验证（81.7%）定量刻画了领域偏移，逐类分析发现下降几乎全部来自胶质瘤（召回 57.5%）；小样本学习曲线实验证明"视觉经验（预训练）使机器每类 14 例即达 92%，接近人类举一反三的效率，而无视觉经验的对照组仅 57%"；Grad-CAM 与层级特征可视化显示模型热区落在病灶样区域附近、层级加工过程与 V1→IT 腹侧通路假说形成类比——在没有病灶标注与眼动数据的条件下，我们将其明确界定为**定性类比**而非人机一致性的定量证据，并给出可验证的下一步路径。

## 1. 选题背景

### 1.1 问题背景

脑肿瘤的早期分型直接影响治疗方案的制定与预后评估。磁共振成像（MRI）是脑部疾病首选的影像学检查手段，但阅片高度依赖放射科医生的经验：医生需要在结构复杂的影像中快速定位可疑病灶并判断其性质——这一过程的认知本质，是**选择性注意**（在海量视觉输入中筛选关键区域）与**模式识别**（将注意到的特征映射到已知类别）的协同。

与此同时，影像科医生的阅片负担日益加重，AI 辅助筛查具有明确的现实价值。而更重要的是，让机器完成与人类相同的视觉诊断任务，恰好为认知科学提供了一个**可检验的计算模型**：机器的"注意"与人类是否一致？机器犯的错误是否具有人类错误模式的特点？这些问题本身就是视觉认知研究的核心关切。

### 1.2 与课程的关联

本项目与认知科学课程的关联体现在三个层面：

1. **视觉注意机制**：通过 Grad-CAM 将卷积神经网络（CNN）做出类别决策时"关注"的图像区域可视化，与人类的选择性注意直接类比，并可定量比较人机注意分布的异同。
2. **层级知觉加工**：CNN 从边缘、纹理等低级特征到语义概念的层级特征提取方式，对应了视觉皮层从 V1 到腹侧通路 IT 区的层级表征假说；迁移学习利用 ImageNet 预训练特征的做法，则可类比人类视觉经验的迁移。
3. **认知计算建模**：以计算模型模拟认知功能、检验模型行为与人类行为的异同，是计算认知科学的标准方法论。本项目中 Grad-CAM 分析正是这一方法论的实践。

### 1.3 项目目标

- 构建一个**完整可演示**的脑肿瘤 MRI 四分类辅助诊断系统（数据 → 训练 → 评估 → 可视化 → Web 部署五环闭环）；
- 在普通 CPU 笔记本的资源约束下达到有竞争力的准确率；
- 超越"报一个准确率数字"，通过外部验证与多模型对比形成严谨的证据链；
- 以注意力可视化为桥梁，开展人机视觉认知的比较分析。

## 2. 系统设计

### 2.1 总体架构

系统由五个环节构成端到端流水线：

```
数据获取与预处理 → 两阶段迁移学习 → 测试集评估 → Grad-CAM 认知分析 → Gradio Web 演示
```

对应四个代码模块（表 1），各模块职责单一、通过文件约定（模型权重、结果 JSON、图像）解耦，全程固定随机种子、日志可复现。

**表 1　系统模块组成**

| 模块 | 文件 | 功能 |
|------|------|------|
| 训练 | `src/train.py` | 两阶段迁移学习训练与验证，支持 ResNet18/34、EfficientNet-B0 三种骨干 |
| 评估 | `src/evaluate.py` | 自动生成混淆矩阵、分类报告、训练曲线 |
| 可视化 | `src/gradcam.py` | 批量生成 Grad-CAM 注意力热力对比图 |
| 外部验证 | `src/external_eval.py` | 在独立来源数据集上进行跨分布泛化评估 |
| 演示 | `app/app.py` | Gradio Web 交互界面：上传 MRI → 输出四类概率 + 注意力热力图 |

### 2.2 数据集与预处理

**主数据集**采用 Kaggle 公开的 *Brain Tumor MRI Dataset*（Nickparvar, 2021）[1]，共 7200 张 T1 增强 MRI，四个类别完全均衡（表 2）。该数据集由 figshare、SARTAJ、Br35H 三个公开来源合并整理。

**表 2　主数据集类别分布**

| 类别 | 训练集 | 测试集 |
|------|--------|--------|
| 胶质瘤（Glioma） | 1400 | 400 |
| 脑膜瘤（Meningioma） | 1400 | 400 |
| 无肿瘤（No tumor） | 1400 | 400 |
| 垂体瘤（Pituitary） | 1400 | 400 |
| 合计 | 5600 | 1600 |

**外部验证集**采用另一独立整理来源的 Kaggle 公开数据集 *Brain Tumors 256×256*[2]，共 3096 张（胶质瘤 901 / 脑膜瘤 913 / 正常 438 / 垂体瘤 844），与训练数据无交集，用于模拟"模型换一家医院"的跨分布测试。

**预处理与增强**：统一缩放至 224×224；训练时施加随机水平翻转、±10° 旋转、亮度/对比度抖动；以 ImageNet 均值方差归一化以匹配预训练分布；训练集再划出 10% 作为验证集（固定随机种子 42）。需要说明的是，初版实现中验证集沿用了训练集的随机增强，会干扰模型选择的稳定性；现已修正为**验证集与测试集共用固定预处理**（`src/train.py`），保证验证指标可比。

**数据审计（泄漏排查）**：对训练 / 测试 / 外部三组共 10296 张图像做了双重查重（`src/data_audit.py`）——（1）MD5 精确查重：三组之间精确重复 **0 对**，排除了最直接的泄漏；（2）8×8 感知哈希粗筛出若干跨组"疑似近似重复"（MRI 黑底灰结构导致粗哈希碰撞率高），再经 16×16 哈希距离与 64×64 像素级 MSE 复核（`src/verify_near_dups.py`），**全部排除**，未发现真实的跨组重复。同时如实记录：训练集内部存在 138 组精确重复（多为数据集自带的增强副本），测试集 15 组、外部集 217 组——组内重复不涉及跨组信息泄漏，但意味着有效样本量略小于名义值，已在结果解读中予以考虑。数据集未提供患者级标识，无法做按患者划分，这是公开整理数据的固有局限，特此声明。

### 2.3 两阶段迁移学习

模型以 ImageNet 预训练的 ResNet18 [3] 为骨干，替换最后全连接层为 4 类分类头。训练采用**两阶段策略**：

- **阶段一（训练分类头）**：冻结全部骨干参数，仅优化新分类头（Adam，lr=1e-3，3 epochs）；
- **阶段二（微调深层）**：解冻最后一个残差块（layer4），以更小学习率微调（lr=1e-4，3 epochs）。

这一设计的理由有三：

1. **预训练特征的可迁移性**：ImageNet 上学到的边缘、纹理等通用视觉特征对医学影像同样有效——这类似于人类医生将日常视觉经验迁移到阅片任务中；
2. **防止灾难性遗忘**：在仅数千张的小数据集上直接全量微调，会快速破坏预训练特征；先固定骨干让分类头收敛，再以小步长微调深层，可稳定提升；
3. **计算可行性**：两阶段策略使无 GPU 的普通笔记本也可完成训练（阶段一每 epoch 约 100 秒，阶段二约 130 秒）。

### 2.4 联想记忆分类模块：现代 Hopfield 网络

标准全连接分类头是**判别式**的——学习一个决策边界。而认知科学的原型理论与样例理论均认为，人类的范畴化（categorization）高度依赖**记忆**：识别新事物时，是在与脑中存储的范例做比较。为此，系统将分类头设计为可替换结构，并实现了**现代 Hopfield 联想记忆头**作为对照：

- **记忆存储**：类别特征原型（类内均值）或可学习记忆模式作为存储模式；
- **联想检索**：查询特征与记忆模式做内积，经 softmax 加权检索后读出类别。现代 Hopfield 网络的这一更新规则与注意力机制在数学上等价（Ramsauer et al., 2020）[6]——**联想记忆与注意力是同一枚硬币的两面**，本项目的"记忆"与"注意"两条认知线索由此在理论上汇合。

### 2.5 可解释性模块：Grad-CAM

Grad-CAM（Gradient-weighted Class Activation Mapping）[4] 取最后一个卷积层的特征图，用目标类别输出对各特征图的梯度做全局平均池化得到通道权重，再加权求和得到类别判别热力图。梯度反映"该区域对最终决策的贡献"，因此热力图可视为**模型决策依据的空间投影**——即机器的"注意"分布。本系统将其同时用于离线案例分析与在线演示的实时输出。

### 2.6 演示系统

基于 Gradio 构建 Web 交互界面：用户上传脑部 MRI 后，系统约 1 秒（CPU）内输出四个类别的预测概率与对应 Grad-CAM 热力图，界面内置四个类别的示例图像供一键试跑，并明确标注"仅供课程演示，不构成医学诊断建议"。

### 3.2 误差分析

混淆矩阵（图 3）揭示了错误的结构：

- **无肿瘤召回率 100%**：辅助筛查场景下"不漏诊"优先于"分得细"，该指标达标意味着系统具备预筛潜力；

### 3.3 外部验证：泛化能力与领域偏移

医学 AI 模型在单一来源数据上取得高指标并不足以证明其实用价值。本项目在独立整理来源的 3096 张外部数据上、不对模型做任何调整直接测试，总体准确率为 **81.7%**，较内部下降 11.3 个百分点（表 4、图 4）。各类别中，胶质瘤召回率由 76.3% 进一步降至 57.5%，再次印证该类的鉴别难度；无肿瘤召回率（97.7%）与垂体瘤（96.1%）保持了较好的跨分布稳定性。

**表 4　外部验证分类别指标（n=3096）**

| 类别 | 精确率 | 召回率 | F1 |
|------|--------|--------|-----|
| 胶质瘤 | 1.000 | 0.575 | 0.730 |
| 脑膜瘤 | 0.751 | 0.847 | 0.796 |
| 无肿瘤 | 0.759 | 0.977 | 0.854 |
| 垂体瘤 | 0.823 | 0.961 | 0.887 |

准确率落差的主要原因是**领域偏移（domain shift）**：不同设备、不同扫描协议产生的影像在灰度、对比度分布上存在系统性差异。典型错误案例分析（`src/error_analysis.py`，图 11）进一步揭示了落差的具体形态：高置信度错误集中出现在 T2/FLAIR 等训练集中稀少的序列类型，以及低对比度、非典型层面的扫描上——模型并非"随机犯错"，而是系统性地在不熟悉的成像风格上失效。这正是医学 AI 落地的核心挑战，也指明了改进方向：训练时引入随机灰度化与直方图均衡增强以学习成像风格不变的特征，或采用特征层面的域适应方法。此外需声明：外部集为主数据集外的独立整理来源，两组间经 MD5 与感知哈希复核无重复图像（见 2.2 节数据审计），但因公开数据均不提供患者标识，"患者级独立"无法直接核验，这是结论外推时需要注意的边界。

### 3.4 多模型对比

为验证骨干网络选择的合理性，对三种骨干进行了系统对比（均经相同两阶段训练，表 5）。

**表 5　三模型对比**

| 模型 | 参数量 | 阶段一（内部） | 阶段二（内部） | 外部验证 |
|------|--------|------------|------------|---------|
| **ResNet18** | 11.2M | 79.1% | **93.0%** | **81.7%** |
| ResNet34 | 21.3M | 79.9% | 91.8% | 79.4% |
| EfficientNet-B0 | 5.3M | 80.4% | 84.0% | 76.9% |

两个发现：

1. **更深不等于更好**：ResNet34 参数量接近翻倍，内部准确率反而低 1.2 个百分点——5600 张的小数据集上，过大的容量更易过拟合训练分布；
2. **结论具有跨分布稳定性**：三个模型在内部与外部评估中的排名完全一致（ResNet18 最优），说明该结论不是某一测试集上的偶然现象。EfficientNet-B0 表现偏弱则与其复合缩放结构需要更长训练周期和更精细正则化有关，3 个 epoch 的微调不足以收敛。

### 3.6 联想记忆 vs 判别式：Hopfield 分类头公平对比与消融

冻结微调骨干（512 维归一化特征），在**同一数据划分、同一训练预算**（Adam lr=1e-3，batch 256，30 epochs）下对比四种分类头，各跑 **5 个随机种子**报告 mean±std；其中 MLP 头专为**参数量对齐**而设（约 6.6 万 vs Hopfield 头约 7.0 万），以控制"额外参数"这一混淆因素（`src/ablate_heads.py`，表 6）。

**表 6　四种分类头公平对比（同一冻结骨干特征，5 种子 mean±std）**

| 分类头 | 参数量 | 训练成本 | 内部准确率 | 外部准确率 |
|--------|--------|---------|-----------|-----------|
| 线性头（判别式基线） | 2,052 | 30 epochs | 92.6% ± 0.0 | 81.6% ± 0.1 |
| Hopfield 原型记忆（零训练） | 0 | **无** | 92.1% | 79.7% |
| MLP 头（参数量对齐对照） | 66,180 | 30 epochs | 93.9% ± 0.0 | 83.3% ± 0.1 |
| Hopfield 可训练记忆头 | 70,277 | 30 epochs | 94.0% ± 0.0* | 83.4%* |

\* Hopfield 记忆头存在训练不稳定现象：5 个种子中 1 个塌陷（测试 75.4%），表内为剔除该种子后的统计；计入全部 5 种子则为 90.4% ± 7.5。

**发现一：零训练的记忆检索即达 92.1%**。仅"记住每类长什么样"（类内均值原型 + softmax 检索）便几乎追平判别式线性头——说明特征空间中类别聚类结构良好；人类识别同样高度依赖既往范例（原型/样例理论），记忆式头在机制上更贴近人类范畴化过程。

**发现二：0.9 个百分点的提升真实，但归因需要诚实**。McNemar 配对检验显示，记忆头对线性头的优势在 4/5 种子上统计显著（p<0.01，胜出种子上 p 最低达 3.6×10⁻⁵）——提升不是随机波动。然而，参数量对齐的 MLP 头达到完全相同的 93.9%：**提升主要来自"更大的参数化头"，而非"联想检索"机制本身**。这一对照把初版结论"记忆头反超"修正为更准确的表述：记忆机制没有性能代价，但也不是性能收益的来源；其价值在于认知建模意义（机制贴近人类范畴化）以及与注意力机制的理论统一。

**发现三：记忆容量存在下限效应**。每类记忆条数消融（{1,2,4,8,16,32} × 3 种子）显示：容量 ≥8 时性能饱和（94.0%）且高度稳定（std≤0.15%）；容量 ≤4 时均值下降且方差剧增（std 高达 10%），部分种子训练塌陷——**联想记忆头需要足够大的记忆容量才能可靠工作**，这与样例理论"范畴表征需要多个范例"的定性预测一致。

（图 9：四种分类头公平对比　`results/ablation_heads.png`）
（图 10：记忆容量消融曲线　`results/hopfield_memory_sweep.png`）

### 3.7 小样本学习曲线：视觉经验的价值

人类医生看几十例即可鉴别肿瘤。为考察"机器需要多少样本"，固定判别式线性头，在每类 14~1400 张（对数轴）范围内变化训练量，并设置三种"视觉经验"条件的对照（图 5）。

**表 7　小样本学习曲线（判别式头，测试准确率）**

| 骨干特征来源 | 每类 14 张 | 每类 70 张 | 每类 140 张 | 每类 1400 张 |
|--------------|-----------|-----------|-------------|--------------|
| 微调骨干（任务视觉经验） | **92.0%** | 92.1% | 92.2% | 92.4% |
| 预训练骨干（通用视觉经验） | 71.6% | 74.3% | 73.8% | 74.7% |
| 随机初始化（无视觉经验，对照） | 56.8% | 56.8% | 56.6% | 56.9% |

（Hopfield 原型记忆头在微调骨干上与之并驾齐驱：91.6%@14 张 → 92.1%@1400 张。）

**结论**：（1）"举一反三"来自经验而非算法魔法——有任务视觉经验时每类 14 张即达 92%，接近人类"数十例上手"的效率；去掉视觉经验，同样算法仅余 57%；（2）经验的贡献可分解为两段：通用视觉经验（预训练）贡献约 +17 pp，任务适应（微调）再贡献约 +17 pp——恰如人类"多年日常视觉经验 + 医学院专科训练"的两段式成长。

### 3.9 Grad-CAM 注意力分析：人机认知的定性类比

对三个类别正确分类样本的 Grad-CAM 可视化（图 7）显示：模型的注意热区均落在影像上的病灶样区域附近，与"放射科医生阅片时优先注视病灶"的模式**形成定性类比**。

必须明确证据边界：本数据集**没有病灶分割标注，也没有人类眼动记录**，因此无法计算热区与真实病灶的重合度，更不能断言"机器注意与人类专家注意定量一致"。Grad-CAM 热区反映的是"对决策有贡献的区域"，它可能落在病灶上，也可能落在与病灶共现的伪迹上；本节所有人机比较均为定性类比，而非验证性结论。

在此边界内，错误案例（图 8）仍提供了一个有价值的定性线索：一张被误判为脑膜瘤的胶质瘤 MRI，其热区依然覆盖异常区域——提示瓶颈**可能**在特征鉴别能力而非区域定位能力，类似人类初学者能定位病灶却无法分辨亚型。这一线索与 3.2 节混淆矩阵的错误结构相互印证，但要成为严格结论，需要病灶标注或眼动数据的定量检验。

注意力可视化的意义不止于工程调试：它把"黑箱分类器"转化为**可与人类比较的认知对象**，并给出了可验证的下一步路径——与眼动实验结合，计算人类注视点与模型热区的 IoU 重叠率，把本节的定性类比升级为定量对比。

## 4. 工作量与创新点

### 4.1 工作量

1. **数据处理**：7200 张主数据集与 3096 张外部数据集的下载、整理、预处理流水线；
2. **模型训练**：三个骨干网络 × 两阶段共 6 轮对比训练与调参，全程固定随机种子、日志可复现，全部在 CPU 笔记本上完成；
3. **评估体系**：混淆矩阵、分类报告、双阶段训练曲线的自动化生成；**跨来源外部泛化验证**与三模型内外对比；
4. **认知实验**：Hopfield 联想记忆头（原型 / 可训练两组）、四种分类头公平对比（5 种子 + McNemar 配对检验 + 参数量对齐 MLP 对照）、记忆容量消融（6 档 × 3 种子）、小样本学习曲线（3 骨干 × 5 数据量级对照）、层级特征可视化、8 组 Grad-CAM 案例分析；
5. **可靠性工程**：全数据泄漏审计（10296 张图像 MD5 + 感知哈希双重复核）、验证集固定预处理修正、外部验证逐类错误案例分析；
6. **系统开发**：Gradio 交互式 Web 演示系统，支持实时推理（CPU 约 1 秒/张）与注意力图输出，含权重缺失、无效图片等友好错误处理；
7. **工程问题与解决**：Windows 中文环境下批量训练因控制台 GBK 编码解码训练日志中断，通过子进程显式指定 UTF-8 编码修复并实现断点续跑。

### 4.2 创新点

1. **认知机制进入方法本身**：以现代 Hopfield 联想记忆替换判别式分类头，借助"现代 Hopfield ≡ 注意力"的理论等价，将记忆与注意两条认知线索统一在一个系统中；并且不止于"换头提分"——通过参数量对齐 MLP 对照、5 种子重复与 McNemar 检验、记忆容量消融，诚实回答了"提升从何而来"（更大的参数化头）与"记忆机制何时可靠"（容量 ≥8 条/类），把方法创新做成了有对照、有检验的因果分析；
2. **以对照实验回答认知问题**：小样本学习曲线（含随机初始化对照组）定量分解了"视觉经验"的贡献，证明机器的举一反三与人一样来自经验积累；外部验证刻画领域偏移；Grad-CAM 对比人机注意与错误模式——三个实验共同支撑"人机视觉认知对比"的主线；
3. **严谨的证据链**：跨来源外部验证（-11.3 pp 的领域偏移）与三模型内外一致的排名，使结论具有跨分布稳定性；
4. **资源约束下的训练策略与完整闭环**：两阶段迁移学习在无 GPU 条件下 79.1% → 93.0%，数据 → 训练 → 评估 → 可视化 → 部署五环全部打通，支持现场互动演示。

## 5. 局限与展望

1. **胶质瘤/脑膜瘤混淆**：后续可引入病灶分割先验引导分类、类别加权损失，或升级到多序列 / 3D MRI 输入；
2. **领域偏移**：外部验证准确率（81.7%）与内部（93.0%）存在差距，且逐类分析显示下降集中于胶质瘤（召回 57.5%）、集中于训练集中稀少的序列类型；随机灰度化、直方图均衡等鲁棒性增强以及域适应是下一步重点；
3. **记忆头训练稳定性**：可训练 Hopfield 头在小记忆容量下存在约 1/5 概率的训练塌陷，容量 ≥8 条/类后稳定；工程上需设容量下限或引入更稳定的初始化/正则化；
4. **Grad-CAM 结论的证据边界**：无病灶标注与眼动数据，人机注意比较目前只能作为定性类比；下一步与眼动实验结合，以注视点—热区 IoU 重叠率实现定量验证，把本工程系统延伸为严格的认知科学研究。

---

## 6. 总结

本项目完成了一个完整可演示的脑肿瘤 MRI 图像分类辅助诊断系统：在无 GPU 约束下以两阶段迁移学习达到内部测试集 93.0% 的准确率，并以现代 Hopfield 联想记忆头（94.0%）验证记忆式分类的可行性。更重要的是，项目用三组对照把"感觉不错的结果"变成了"经得起追问的结论"：全数据泄漏审计排除跨组重复；四种分类头的公平对比（5 种子 + McNemar + 参数量对齐 MLP）表明记忆头的优势真实但源于参数量而非联想机制本身，记忆容量消融给出可靠工作的容量下限；外部验证的逐类错误分析把"81.7%"落实为具体的失效模式（稀少序列类型上的系统性失败）。围绕"人机视觉认知的异同"这一主线：跨来源外部验证刻画了领域偏移（81.7%）；三模型对比确认了模型选择的跨分布稳定性；小样本学习曲线证明视觉经验是机器"举一反三"的来源（每类 14 例即 92%，无经验对照仅 57%）；Grad-CAM 与层级特征可视化给出人机注意的定性类比与 V1→IT 层级加工的模型内实证，并诚实标注了证据边界。项目实践了认知科学"以计算模型研究认知"的方法论：**让机器"学会看"，再追问它"怎么看"、"怎么记"、"怎么学"**——并确保每一个回答都配有可复核的证据。
