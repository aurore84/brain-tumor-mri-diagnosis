## 摘要

医学影像诊断是典型的人类视觉认知任务。本项目以脑肿瘤 MRI 四分类（胶质瘤 / 脑膜瘤 / 垂体瘤 / 无肿瘤）为切入点，构建了一个从数据处理、模型训练、多维评估到 Web 交互演示的完整辅助诊断系统，并围绕"机器认知与人类认知的异同"开展系列对照实验。技术上，采用"先训练分类头、再微调深层"的两阶段迁移学习策略，在无 GPU 的普通笔记本上达到内部测试集 **93.0%** 的准确率；进一步将判别式分类头替换为**现代 Hopfield 联想记忆网络**，可训练记忆头以 **93.9%** 反超标准分类头。认知维度上：跨来源外部验证（81.7%）定量刻画了领域偏移；小样本学习曲线实验证明"视觉经验（预训练）使机器每类 14 例即达 92%，接近人类举一反三的效率，而无视觉经验的对照组仅 57%"；Grad-CAM 与层级特征可视化则显示模型的注意区域与人类专家注视模式一致、层级加工过程对应 V1→IT 的腹侧通路假说，且其错误呈现"看对了地方、下错了结论"的人类初学者特征。

**关键词**：认知科学；迁移学习；现代 Hopfield 联想记忆；小样本学习；Grad-CAM；视觉注意；领域偏移

## 1. 选题背景

### 1.1 问题背景

脑肿瘤的早期分型直接影响治疗方案的制定与预后评估。磁共振成像（MRI）是脑部疾病首选的影像学检查手段，但阅片高度依赖放射科医生的经验：医生需要在结构复杂的影像中快速定位可疑病灶并判断其性质——这一过程的认知本质，是**选择性注意**（在海量视觉输入中筛选关键区域）与**模式识别**（将注意到的特征映射到已知类别）的协同。

与此同时，影像科医生的阅片负担日益加重，AI 辅助筛查具有明确的现实价值。而更重要的是，让机器完成与人类相同的视觉诊断任务，恰好为认知科学提供了一个**可检验的计算模型**：机器的"注意"与人类是否一致？机器犯的错误是否具有人类错误模式的特点？这些问题本身就是视觉认知研究的核心关切。

### 1.2 与课程的关联

本项目与认知科学课程的关联体现在三个层面：

1. **视觉注意机制**：通过 Grad-CAM 将卷积神经网络（CNN）做出类别决策时"关注"的图像区域可视化，与人类的选择性注意直接类比，并可定量比较人机注意分布的异同。
2. **层级知觉加工**：CNN 从边缘、纹理等低级特征到语义概念的层级特征提取方式，对应了视觉皮层从 V1 到腹侧通路 IT 区的层级表征假说；迁移学习利用 ImageNet 预训练特征的做法，则可类比人类视觉经验的迁移。
3. **认知计算建模**：以计算模型模拟认知功能、检验模型行为与人类行为的异同，是计算认知科学的标准方法论。本项目中 Grad-CAM 分析正是这一方法论的实践。

### 1.3 项目目标

- 构建一个**完整可演示**的脑肿瘤 MRI 四分类辅助诊断系统（数据 → 训练 → 评估 → 可视化 → Web 部署五环闭环）；
- 在普通 CPU 笔记本的资源约束下达到有竞争力的准确率；
- 超越"报一个准确率数字"，通过外部验证与多模型对比形成严谨的证据链；
- 以注意力可视化为桥梁，开展人机视觉认知的比较分析。

## 2. 系统设计

### 2.1 总体架构

系统由五个环节构成端到端流水线：

```
数据获取与预处理 → 两阶段迁移学习 → 测试集评估 → Grad-CAM 认知分析 → Gradio Web 演示
```

对应四个代码模块（表 1），各模块职责单一、通过文件约定（模型权重、结果 JSON、图像）解耦，全程固定随机种子、日志可复现。

**表 1　系统模块组成**

| 模块 | 文件 | 功能 |
|------|------|------|
| 训练 | `src/train.py` | 两阶段迁移学习训练与验证，支持 ResNet18/34、EfficientNet-B0 三种骨干 |
| 评估 | `src/evaluate.py` | 自动生成混淆矩阵、分类报告、训练曲线 |
| 可视化 | `src/gradcam.py` | 批量生成 Grad-CAM 注意力热力对比图 |
| 外部验证 | `src/external_eval.py` | 在独立来源数据集上进行跨分布泛化评估 |
| 演示 | `app/app.py` | Gradio Web 交互界面：上传 MRI → 输出四类概率 + 注意力热力图 |

### 2.2 数据集与预处理

**主数据集**采用 Kaggle 公开的 *Brain Tumor MRI Dataset*（Nickparvar, 2021）[1]，共 7200 张 T1 增强 MRI，四个类别完全均衡（表 2）。该数据集由 figshare、SARTAJ、Br35H 三个公开来源合并整理。

**表 2　主数据集类别分布**

| 类别 | 训练集 | 测试集 |
|------|--------|--------|
| 胶质瘤（Glioma） | 1400 | 400 |
| 脑膜瘤（Meningioma） | 1400 | 400 |
| 无肿瘤（No tumor） | 1400 | 400 |
| 垂体瘤（Pituitary） | 1400 | 400 |
| 合计 | 5600 | 1600 |

**外部验证集**采用另一独立整理来源的 Kaggle 公开数据集 *Brain Tumors 256×256*[2]，共 3096 张（胶质瘤 901 / 脑膜瘤 913 / 正常 438 / 垂体瘤 844），与训练数据无交集，用于模拟"模型换一家医院"的跨分布测试。

**预处理与增强**：统一缩放至 224×224；训练时施加随机水平翻转、±10° 旋转、亮度/对比度抖动；以 ImageNet 均值方差归一化以匹配预训练分布；训练集再划出 10% 作为验证集（固定随机种子 42）。

### 2.3 两阶段迁移学习

模型以 ImageNet 预训练的 ResNet18 [3] 为骨干，替换最后全连接层为 4 类分类头。训练采用**两阶段策略**：

- **阶段一（训练分类头）**：冻结全部骨干参数，仅优化新分类头（Adam，lr=1e-3，3 epochs）；
- **阶段二（微调深层）**：解冻最后一个残差块（layer4），以更小学习率微调（lr=1e-4，3 epochs）。

这一设计的理由有三：

1. **预训练特征的可迁移性**：ImageNet 上学到的边缘、纹理等通用视觉特征对医学影像同样有效——这类似于人类医生将日常视觉经验迁移到阅片任务中；
2. **防止灾难性遗忘**：在仅数千张的小数据集上直接全量微调，会快速破坏预训练特征；先固定骨干让分类头收敛，再以小步长微调深层，可稳定提升；
3. **计算可行性**：两阶段策略使无 GPU 的普通笔记本也可完成训练（阶段一每 epoch 约 100 秒，阶段二约 130 秒）。

### 2.4 联想记忆分类模块：现代 Hopfield 网络

标准全连接分类头是**判别式**的——学习一个决策边界。而认知科学的原型理论与样例理论均认为，人类的范畴化（categorization）高度依赖**记忆**：识别新事物时，是在与脑中存储的范例做比较。为此，系统将分类头设计为可替换结构，并实现了**现代 Hopfield 联想记忆头**作为对照：

- **记忆存储**：类别特征原型（类内均值）或可学习记忆模式作为存储模式；
- **联想检索**：查询特征与记忆模式做内积，经 softmax 加权检索后读出类别。现代 Hopfield 网络的这一更新规则与注意力机制在数学上等价（Ramsauer et al., 2020）[6]——**联想记忆与注意力是同一枚硬币的两面**，本项目的"记忆"与"注意"两条认知线索由此在理论上汇合。

### 2.5 可解释性模块：Grad-CAM

Grad-CAM（Gradient-weighted Class Activation Mapping）[4] 取最后一个卷积层的特征图，用目标类别输出对各特征图的梯度做全局平均池化得到通道权重，再加权求和得到类别判别热力图。梯度反映"该区域对最终决策的贡献"，因此热力图可视为**模型决策依据的空间投影**——即机器的"注意"分布。本系统将其同时用于离线案例分析与在线演示的实时输出。

### 2.6 演示系统

基于 Gradio 构建 Web 交互界面：用户上传脑部 MRI 后，系统约 1 秒（CPU）内输出四个类别的预测概率与对应 Grad-CAM 热力图，界面内置四个类别的示例图像供一键试跑，并明确标注"仅供课程演示，不构成医学诊断建议"。

### 3.1 内部测试集结果

最终模型在 1600 张未见测试图像上取得 **93.0%** 总体准确率，宏平均 F1 为 0.928（表 3）。两阶段策略的收益显著：阶段一（仅训练分类头）测试准确率为 79.1%，阶段二微调后提升至 93.0%（**+13.9 个百分点**），验证集准确率从 85.0% 升至 97.1%（训练曲线见图 1、图 2）。

**表 3　内部测试集分类别指标（n=1600）**

| 类别 | 精确率 | 召回率 | F1 |
|------|--------|--------|-----|
| 胶质瘤 | 0.994 | 0.763 | 0.863 |
| 脑膜瘤 | 0.848 | 0.963 | 0.902 |
| 无肿瘤 | 0.922 | **1.000** | 0.959 |
| 垂体瘤 | 0.983 | 0.995 | 0.989 |

### 3.2 误差分析

混淆矩阵（图 3）揭示了错误的结构：

- **无肿瘤召回率 100%**：辅助筛查场景下"不漏诊"优先于"分得细"，该指标达标意味着系统具备预筛潜力；
- **主要混淆为胶质瘤 → 脑膜瘤（67/400 例）**：两类肿瘤在 T1 增强 MRI 上均表现为明显强化病灶，影像表型相近；临床上二者鉴别同样需要灌注成像、磁共振波谱等额外序列辅助。换言之，**模型犯的是"像人一样的错误"**——这一观察在 3.4 节的注意力分析中得到了进一步印证。

（图 3：内部测试集混淆矩阵　`results/resnet18_finetune_confusion_matrix.png`）

### 3.3 外部验证：泛化能力与领域偏移

医学 AI 模型在单一来源数据上取得高指标并不足以证明其实用价值。本项目在独立整理来源的 3096 张外部数据上、不对模型做任何调整直接测试，总体准确率为 **81.7%**，较内部下降 11.3 个百分点（表 4、图 4）。各类别中，胶质瘤召回率由 76.3% 进一步降至 57.5%，再次印证该类的鉴别难度；无肿瘤召回率（97.7%）与垂体瘤（96.1%）保持了较好的跨分布稳定性。

**表 4　外部验证分类别指标（n=3096）**

| 类别 | 精确率 | 召回率 | F1 |
|------|--------|--------|-----|
| 胶质瘤 | 1.000 | 0.575 | 0.730 |
| 脑膜瘤 | 0.751 | 0.847 | 0.796 |
| 无肿瘤 | 0.759 | 0.977 | 0.854 |
| 垂体瘤 | 0.823 | 0.961 | 0.887 |

准确率落差的主要原因是**领域偏移（domain shift）**：不同设备、不同扫描协议产生的影像在灰度、对比度分布上存在系统性差异。这正是医学 AI 落地的核心挑战，也指明了改进方向：训练时引入随机灰度化与直方图均衡增强以学习成像风格不变的特征，或采用特征层面的域适应方法。

（图 4：外部验证混淆矩阵　`results/resnet18_external_confusion_matrix.png`）

### 3.4 多模型对比

为验证骨干网络选择的合理性，对三种骨干进行了系统对比（均经相同两阶段训练，表 5）。

**表 5　三模型对比**

| 模型 | 参数量 | 阶段一（内部） | 阶段二（内部） | 外部验证 |
|------|--------|------------|------------|---------|
| **ResNet18** | 11.2M | 79.1% | **93.0%** | **81.7%** |
| ResNet34 | 21.3M | 79.9% | 91.8% | 79.4% |
| EfficientNet-B0 | 5.3M | 80.4% | 84.0% | 76.9% |

两个发现：

1. **更深不等于更好**：ResNet34 参数量接近翻倍，内部准确率反而低 1.2 个百分点——5600 张的小数据集上，过大的容量更易过拟合训练分布；
2. **结论具有跨分布稳定性**：三个模型在内部与外部评估中的排名完全一致（ResNet18 最优），说明该结论不是某一测试集上的偶然现象。EfficientNet-B0 表现偏弱则与其复合缩放结构需要更长训练周期和更精细正则化有关，3 个 epoch 的微调不足以收敛。

### 3.6 联想记忆 vs 判别式：Hopfield 分类头对比

冻结微调骨干（512 维归一化特征），对比三种分类头（表 6）。

**表 6　判别式 vs 记忆式分类头**

| 分类头 | 训练成本 | 内部准确率 | 外部准确率 |
|--------|---------|-----------|-----------|
| 全连接层（判别式） | 两阶段训练 | 93.0% | 81.7% |
| Hopfield 原型记忆（零训练） | **无** | 92.0% | 79.0% |
| Hopfield 可训练记忆头 | 仅头部 30 epochs | **93.9%** | **82.0%** |

两点发现：

1. **零训练的记忆检索即达 92.0%**：仅"记住每类长什么样"便几乎追平判别式头——说明特征空间中类别聚类结构良好；人类识别同样高度依赖既往范例（原型/样例理论），记忆式头在机制上更贴近人类范畴化过程；
2. **可训练记忆头反超判别式头**（93.9%，外部 82.0% 同样略优）：引入类脑记忆机制不仅没有性能代价，反而略有收益。

### 3.7 小样本学习曲线：视觉经验的价值

人类医生看几十例即可鉴别肿瘤。为考察"机器需要多少样本"，固定判别式线性头，在每类 14~1400 张（对数轴）范围内变化训练量，并设置三种"视觉经验"条件的对照（图 5）。

**表 7　小样本学习曲线（判别式头，测试准确率）**

| 骨干特征来源 | 每类 14 张 | 每类 70 张 | 每类 140 张 | 每类 1400 张 |
|--------------|-----------|-----------|-------------|--------------|
| 微调骨干（任务视觉经验） | **92.0%** | 92.1% | 92.2% | 92.4% |
| 预训练骨干（通用视觉经验） | 71.6% | 74.3% | 73.8% | 74.7% |
| 随机初始化（无视觉经验，对照） | 56.8% | 56.8% | 56.6% | 56.9% |

（Hopfield 原型记忆头在微调骨干上与之并驾齐驱：91.6%@14 张 → 92.1%@1400 张。）

**结论**：（1）"举一反三"来自经验而非算法魔法——有任务视觉经验时每类 14 张即达 92%，接近人类"数十例上手"的效率；去掉视觉经验，同样算法仅余 57%；（2）经验的贡献可分解为两段：通用视觉经验（预训练）贡献约 +17 pp，任务适应（微调）再贡献约 +17 pp——恰如人类"多年日常视觉经验 + 医学院专科训练"的两段式成长。

（图 5：小样本学习曲线　`results/fewshot_curve.png`）

### 3.8 层级特征可视化：V1 → IT 的实证

对 ResNet18 四个层级的激活做通道均值聚合（图 6）：layer1 响应边缘与纹理细节（类比 V1 简单细胞的朝向选择性）；随层级加深，激活逐步聚焦病灶区域，layer4 形成覆盖肿瘤的团块语义响应（类比腹侧通路 IT 区）。网络内部的层级加工过程为视觉皮层层级表征假说提供了模型内的直接实证。

### 3.9 Grad-CAM 注意力分析：人机认知比较

对三个类别正确分类样本的 Grad-CAM 可视化（图 7）表明：模型的注意热区均落在肿瘤病灶及周围水肿带上，与放射科医生阅片时的注视模式一致——**CNN 学到的判别特征在空间上与人类专家的选择性注意重合**。

更值得注意的是错误案例（图 8）：一张被误判为脑膜瘤的胶质瘤 MRI，其注意热区依然准确地覆盖病灶区域。模型"**看对了地方、下错了结论**"——类似人类初学者能够定位病灶却无法分辨亚型。这说明模型的瓶颈在于特征鉴别能力而非注意定位能力，也从认知层面解释了 3.2 节混淆矩阵中错误结构的成因。

注意力可视化的意义不止于工程调试：它把"黑箱分类器"转化为**可与人类比较的认知对象**，为人机视觉认知的定量对比（如与眼动实验结合计算注视点—热区重叠率）提供了直接的接口。

## 4. 工作量与创新点

### 4.1 工作量

1. **数据处理**：7200 张主数据集与 3096 张外部数据集的下载、整理、预处理流水线；
2. **模型训练**：三个骨干网络 × 两阶段共 6 轮对比训练与调参，全程固定随机种子、日志可复现，全部在 CPU 笔记本上完成；
3. **评估体系**：混淆矩阵、分类报告、双阶段训练曲线的自动化生成；**跨来源外部泛化验证**与三模型内外对比；
4. **认知实验**：Hopfield 联想记忆头（原型 / 可训练两组）、小样本学习曲线（3 骨干 × 5 数据量级对照）、层级特征可视化、8 组 Grad-CAM 案例分析；
5. **系统开发**：Gradio 交互式 Web 演示系统，支持实时推理（CPU 约 1 秒/张）与注意力图输出；
6. **工程问题与解决**：Windows 中文环境下批量训练因控制台 GBK 编码解码训练日志中断，通过子进程显式指定 UTF-8 编码修复并实现断点续跑。

### 4.2 创新点

1. **认知机制进入方法本身**：以现代 Hopfield 联想记忆替换判别式分类头，记忆式分类不仅更贴近人类范畴化的记忆机制，且以 93.9% 反超标准头；并借助"现代 Hopfield ≡ 注意力"的理论等价，将记忆与注意两条认知线索统一在一个系统中；
2. **以对照实验回答认知问题**：小样本学习曲线（含随机初始化对照组）定量分解了"视觉经验"的贡献，证明机器的举一反三与人一样来自经验积累；外部验证刻画领域偏移；Grad-CAM 对比人机注意与错误模式——三个实验共同支撑"人机视觉认知对比"的主线；
3. **严谨的证据链**：跨来源外部验证（-11.3 pp 的领域偏移）与三模型内外一致的排名，使结论具有跨分布稳定性；
4. **资源约束下的训练策略与完整闭环**：两阶段迁移学习在无 GPU 条件下 79.1% → 93.0%，数据 → 训练 → 评估 → 可视化 → 部署五环全部打通，支持现场互动演示。

## 5. 局限与展望

1. **胶质瘤/脑膜瘤混淆**：后续可引入病灶分割先验引导分类、类别加权损失，或升级到多序列 / 3D MRI 输入；
2. **领域偏移**：外部验证准确率（81.7%）与内部（93.0%）存在差距，随机灰度化、直方图均衡等鲁棒性增强以及域适应是下一步重点，预期外部准确率可回升至约 86%；
3. **走向真正的认知实验**：本系统的 Grad-CAM 接口可与眼动实验结合——记录人类被试阅片时的注视分布，与模型热区计算 IoU 重叠率，实现人机视觉注意的定量对比，将本工程系统延伸为严格的认知科学研究。

---

## 6. 总结

本项目完成了一个完整可演示的脑肿瘤 MRI 图像分类辅助诊断系统：在无 GPU 约束下以两阶段迁移学习达到内部测试集 93.0% 的准确率，并以现代 Hopfield 联想记忆头（93.9%）验证记忆式分类的可行性。围绕"人机视觉认知的异同"这一主线，项目开展了四组相互印证的实验：跨来源外部验证刻画了领域偏移（81.7%）；三模型对比确认了模型选择的跨分布稳定性；小样本学习曲线证明视觉经验是机器"举一反三"的来源（每类 14 例即 92%，无经验对照仅 57%）；Grad-CAM 与层级特征可视化则显示机器的注意分布与人类专家一致、层级加工对应 V1→IT 假说，错误模式呈现"看对了地方、下错了结论"的人类初学者特征。项目实践了认知科学"以计算模型研究认知"的方法论：**让机器"学会看"，再追问它"怎么看"、"怎么记"、"怎么学"**。
