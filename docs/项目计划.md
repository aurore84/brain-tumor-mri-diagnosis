# 认知科学大作业：脑肿瘤 MRI 图像分类辅助诊断系统

## 一、项目概述
基于迁移学习的脑肿瘤 MRI 图像四分类系统（胶质瘤 / 脑膜瘤 / 垂体瘤 / 无肿瘤），
附带 Grad-CAM 注意力可视化（类比人类视觉注意机制，体现认知科学相关度），
并提供 Gradio Web 交互界面用于现场演示。

## 二、目录结构
```
myproject/
├── data/        # 数据集（脑肿瘤 MRI，Kaggle 公开数据）
├── src/         # 训练与评估脚本
├── models/      # 训练好的模型权重
├── results/     # 实验结果（准确率、混淆矩阵、Grad-CAM 图）
├── app/         # Gradio Web 演示界面
└── docs/        # 文档、PPT 素材、报告
```
